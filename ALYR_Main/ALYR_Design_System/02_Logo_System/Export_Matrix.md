# Logo Export Matrix

| Need | Use | Preferred file |
|---|---|---|
| Website header on light | Horizontal Carbon Volt | SVG |
| Website header on dark | Horizontal Reversed | SVG |
| Proposal/letterhead | Horizontal Carbon Volt | SVG or print PDF placement |
| One-color contract/stamp | Horizontal Monochrome Black | SVG |
| Social avatar | Standalone symbol in platform file | PNG |
| App launcher | App icon master | PNG platform sizes |
| Browser tab | Favicon | SVG + ICO + PNG fallback |
| Exterior sign | Standalone or horizontal monochrome | SVG supplied to fabricator |
| Embroidery | Simplified monochrome symbol | SVG; test stitch proof |
| Small watermark | Wordmark monochrome at 8–12% opacity | SVG |

## File format guidance

- **SVG:** web, UI, signage, editable vector workflows.
- **PNG:** social platforms, chat systems and software that does not support SVG.
- **ICO:** Windows/browser fallback only.
- **PDF/EPS:** create from the master SVG through a print professional when a vendor explicitly requires it.

Never convert a PNG back to vector.
