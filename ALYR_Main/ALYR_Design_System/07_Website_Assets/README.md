# Website Assets

## Graphic elements

- `command-grid.svg` — quiet structural grid for sections and diagrams.
- `fold-path.svg` — transformation journey or before/after movement.
- `signal-rail.svg` — dark header, CTA or operational timeline.
- `dot-field.svg` — data, network or orchestration visual.
- `section-divider.svg` — long-form editorial transition.

## Rules

- Treat graphic elements as spatial structure, not wallpaper.
- Use at low contrast behind content.
- One strong element per viewport is normally enough.
- Do not combine the dot field, grid and rail in the same section.
- Volt paths must correspond to progress, selection or priority.
- Prefer SVG in production; PNG exports are previews/fallbacks.

## Website identity pattern

The most recognizable ALYR page combines:

1. Large precise headline with an intentional line break.
2. A slim Volt signal aligned to the headline or next action.
3. Command-grid or diagonal fold geometry extending beyond the content column.
4. Dense operational evidence presented without decorative cards.
