# Font package

The ALYR system specifies:

- Instrument Sans Variable — primary Latin interface and editorial family.
- IBM Plex Sans Arabic — Arabic companion.
- IBM Plex Mono — operational metadata and code.

Before public production deployment:

1. Download fonts from the official publisher or Google Fonts repository.
2. Keep the applicable SIL Open Font License files with the font binaries.
3. Self-host WOFF2 files in this folder or the application's managed asset pipeline.
4. Use `font-display: swap`.
5. Subset only after Arabic and multilingual requirements are confirmed.

Do not use the ALYR logo artwork as a typeface. The wordmark is available only as locked vector paths.
