# Experience Patterns

## 1. Lead to working session

**Use for:** website and campaign conversion.

Flow: problem-specific landing page → qualification form → preferred channel/time → confirmation → CRM task → human follow-up.

Design rule: ask only what changes routing. Do not make a prospect complete a full discovery questionnaire before contact.

## 2. Transformation audit intake

Flow: scope → business units → current tools → workflow evidence → goals → secure document upload → review summary → submit.

Key states: save and resume, document security notice, missing-item summary, named next step and expected response time.

## 3. Client portal home

Priority order:

1. Decision or action required from client.
2. Current phase and next milestone.
3. Deliverables and approvals.
4. Open questions and risks.
5. Recent activity.

Avoid a decorative dashboard of metrics with no action path.

## 4. Case/workflow tracker

Show human-readable status, owner, last update, next step, due date and blockers. Internally, preserve the detailed workflow state; externally, translate technical states into language a client understands.

## 5. AI-assisted work

Every AI result includes:

- Source or data boundary.
- Confidence/limitation when material.
- Human review state.
- Clear edit, accept and reject actions.
- Audit record for high-risk outputs.

Never style AI output as already approved.

## 6. Approval

Flow: summary → changes since last review → evidence/source → approve/request changes → confirmation and audit log.

Approval actions must state their consequence. Destructive or irreversible approvals require an explicit second step.

## 7. Empty state

Explain why the area matters, what will appear, and the most useful first action. Do not fill empty states with illustration alone.

## 8. Error recovery

Preserve user input, name what failed, separate retryable from blocking errors, and offer a human route when the system cannot recover.

## 9. Bilingual experience

Language switching preserves the current route and task state. Arabic is full RTL, including layout flow, navigation and step direction. IDs, numbers and mixed-script data are tested explicitly.

## 10. Consent and sensitive documents

Before upload, explain purpose, access, retention and supported formats. After upload, show file name, status, scan result and delete/replace control where policy permits.
