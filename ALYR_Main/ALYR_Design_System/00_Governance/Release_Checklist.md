# Release Checklist

## Brand integrity

- [ ] Command Fold geometry matches the approved master.
- [ ] The cut-Y wordmark is an SVG/path asset, not typed text.
- [ ] Volt is used as signal, not background decoration.
- [ ] Clear space and minimum size rules are satisfied.
- [ ] No unapproved gradients, shadows or outline effects are applied to the logo.

## Product quality

- [ ] Keyboard focus is visible on every interactive element.
- [ ] Text and control contrast pass WCAG AA.
- [ ] Error, empty, loading, success and disabled states exist.
- [ ] Mobile behavior is designed rather than simply shrunk.
- [ ] RTL layout is tested for Arabic experiences.
- [ ] Reduced-motion behavior is implemented.

## Content

- [ ] Claims are specific and supportable.
- [ ] Labels describe actions, not vague concepts.
- [ ] Arabic content is reviewed by a fluent human editor.
- [ ] AI output has a named human approver.

## Delivery

- [ ] Source and exports are both included.
- [ ] Asset inventory and hashes are regenerated.
- [ ] Version and changelog are updated.
- [ ] Desktop and mobile showcase screenshots are reviewed.
