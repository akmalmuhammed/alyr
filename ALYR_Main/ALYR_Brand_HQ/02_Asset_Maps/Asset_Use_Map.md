# Asset Use Map

## Approved hierarchy

| Need | Use this folder | Rule |
|---|---|---|
| Primary logo | `ALYR_Design_System/02_Logo_System/01_Master_SVG/` | Use Carbon Volt on light surfaces; reversed on Carbon. |
| App/favicons | `ALYR_Design_System/04_App_and_Favicon/` | Never crop the wordmark into a circular avatar. |
| Social profiles | `ALYR_Design_System/05_Social_Media/01_Profile_Pictures/` | Use the standalone symbol. |
| UI icons | `ALYR_Design_System/03_Icon_System/UI_Icons_SVG/` | Keep the 24px stroke family consistent. |
| UI tokens | `ALYR_Design_System/06_UI_UX_System/Design_Tokens/` | Consume semantic tokens; do not scatter hex values. |
| Website graphics | `ALYR_Design_System/07_Website_Assets/` | Use geometry to clarify structure, not as decoration. |
| Proposals/slides | `ALYR_Design_System/08_Document_System/` | Carbon for decisions, Paper for analysis. |
| Social/campaigns | `ALYR_Design_System/05_Social_Media/03_Post_Templates/` | One claim, one signal, one action. |

## Locked identity

- F1 Command Fold symbol.
- Custom cut-Y ALYR wordmark.
- Carbon `#15171A`, Volt `#B7F34A`, Monochrome foundation.
- Instrument Sans, IBM Plex Sans Arabic, IBM Plex Mono.
- Light-first product surfaces; Carbon for command and premium moments.
- Volt is reserved for action, progress, confirmed state or one strategic signal.

## Never

- Retype or redraw the wordmark.
- Stretch, recolor or alter the cut-Y.
- Use unapproved logo screenshots as masters.
- Turn Volt into a full-page decorative background.
- Add generic AI robots, glowing brains, fake metrics or decorative gradient blobs.

## Delivery checklist

Before handing an asset to a client, verify: correct master, correct clear space, correct color role, correct language/RTL, readable contrast, correct export size, source file location and approval status.
