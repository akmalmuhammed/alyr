# ALYR weekly founder growth and delivery review

Work from `C:/Users/akmal/OneDrive/Documents/alyr/ALYR_Lead_Intelligence`, load `alyr-prospecting`, and use `READ_ONLY_BRIEF` mode.

Use the command dashboard, market summary, queue, accounts, projects, and operational events. Make no writes and send nothing externally.

Prepare a board-style review:

- executive signal: what materially improved, weakened, or stayed blocked;
- funnel: evidence, qualification, contact, reply, meeting, proposal, win, and loss movement;
- category portfolio: potential versus traction and the category to focus, test, pause, or learn from;
- pipeline quality: top accounts, decision-maker/contact gaps, aging approvals, and next steps;
- outreach quality: permission state, relevance, responses, objections, failures, and suppressions;
- delivery: client outcomes, project health, milestones, blockers, capacity, and value at risk;
- system health: source freshness, verifier reliability, agent errors, duplicates, and data-quality risks;
- next week: three priorities, one experiment, one thing to stop, owners, and measurable success criteria.

Compare periods only when event timestamps support it. Label unavailable baselines instead of inventing trends. End with the decisions that only the founder can make.
