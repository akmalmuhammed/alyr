# ALYR Brand HQ export map

The canonical export folders remain in `../ALYR_Design_System`. Use this map when packaging a client handoff:

- `logos/` → `02_Logo_System/01_Master_SVG` + selected `02_PNG_Exports`
- `icons/` → `03_Icon_System/UI_Icons_SVG`
- `app-icons/` → `04_App_and_Favicon`
- `social/` → `05_Social_Media`
- `tokens/` → `06_UI_UX_System/Design_Tokens`
- `website/` → `07_Website_Assets`
- `documents/` → `08_Document_System`
- `content-motion/` → `09_Content_and_Motion`

Never create a second production export by retyping the wordmark or editing a PNG.
