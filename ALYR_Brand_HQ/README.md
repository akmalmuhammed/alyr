# ALYR Brand HQ

ALYR Brand HQ is the operating layer around the approved `ALYR_Design_System` source of truth. It explains **why ALYR exists, what ALYR sells, how ALYR delivers it, and how every brand/product asset is maintained**.

## Start here

1. Read [`01_Strategy/ALYR_Strategic_Operating_Model.md`](01_Strategy/ALYR_Strategic_Operating_Model.md).
2. Use [`02_Asset_Maps/Asset_Use_Map.md`](02_Asset_Maps/Asset_Use_Map.md) to find the right approved asset.
3. Use [`03_Product_UX/UX_Product_Principles.md`](03_Product_UX/UX_Product_Principles.md) for websites, dashboards and portals.
4. Use [`04_Growth_and_Pipeline/Transformation_Pipeline.md`](04_Growth_and_Pipeline/Transformation_Pipeline.md) to move a prospect from discovery to measurable adoption.
5. Follow [`05_Governance/Release_and_Approval_Process.md`](05_Governance/Release_and_Approval_Process.md) before publishing changes.
6. Use [`06_Fonts/Font_Implementation.md`](06_Fonts/Font_Implementation.md) for licensed font setup.

## Repository rule

This folder contains strategy, maps and operating guidance. Production artwork stays in `ALYR_Design_System`; application-specific assets stay with their application. Do not create a second logo master here.
