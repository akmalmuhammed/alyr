# ALYR as a suite of products, led by ALYR Agent: founder decisions

17 Oct 2026, in conversation with the founder. They override anything else in this folder. They go into `docs/decisions.md` as one decision entry (the next free number) with the product change that applies them.

| Topic | Decision |
|---|---|
| Company | ALYR is the business agent for owner-run businesses in Qatar, with a suite of products in one workspace. The public homepage presents the suite the way large companies present a product portfolio |
| Products, in this order | **ALYR Chat** (WhatsApp orders, team inbox, order tracking), **ALYR Bookings** (appointments, services, reminders, no-shows; its own product, split out of Chat), **ALYR Agent** (business intelligence: the dashboard, the Sunday report, suggested actions), **ALYR Accounts** (credit accounts: who owes you). **ALYR Payroll** stays listed as coming. **No separate Pay product**: payment links stay a module inside Chat and Bookings |
| The name "Agent" | Kept. The founder will add AI later. Until a model is in the product (D-012), no page or screen says or implies AI: no "AI", "smart", "learns", "understands", "thinks" or sparkles. The Agent watches the numbers, flags what changed and suggests one action, by rules anyone can check |
| The workspace home | The client workspace's home screen (`/app`) becomes the ALYR Agent dashboard: a premium, traction-friendly business-intelligence screen built on the shop's real data |
| The homepage figure | The public homepage shows that same dashboard component, fed with sample data for the fictional Qirfa Bakery (and a salon and a clinic for the business-type switch), so the homepage shows a real screen, not a mock-up |
| Product pages | Each live product gets its own page like `/chat`: who it is for, how it works, modern visuals, real screens. `/bookings`, `/agent`, `/accounts`, in English and Arabic. Payroll gets no page until it is built |
| Suggestions | Every suggestion the Agent makes links to a screen or action that exists. Anything not built yet (for example a message to many customers, which needs marketing opt-in, ALY-44) is shown as information without a button |
| Unchanged | Prices stay off the public site until the CR (D-034, `NEXT_PUBLIC_ALYR_OFFER`). No invented customers or metrics on the public site; sample data is captioned as sample, as today |

Defaults chosen by the creative director, open to the founder:
- ALYR Agent is included in every subscription. It is what proves the subscription's worth every week, which matters on a month-to-month term.
- The product names stay in Latin in both languages ("ALYR Bookings"), each with an Arabic descriptor, as "ALYR Chat" does today (D-025).
