# Color System

## Brand palette

| Token | Hex | Role |
|---|---:|---|
| Carbon | `#15171A` | Master brand color, headings, dark surfaces |
| Volt | `#B7F34A` | Primary action, progress, confirmation, strategic signal |
| Mist | `#E9ECEF` | Soft divisions and quiet backgrounds |
| Concrete | `#A7ADB5` | Secondary information on dark surfaces |
| Monochrome Black | `#050505` | One-color production and high-density print |
| White | `#FFFFFF` | Master reverse artwork and export transparency checks |

## Interface neutrals

The UI uses softened black and white to reduce glare while preserving the official monochrome logo variants.

| Token | Hex | Usage |
|---|---:|---|
| Canvas light | `#F6F7F3` | Default page background |
| Surface light | `#FFFFFF` | Controls and raised content |
| Canvas dark | `#0E1012` | Dark application shell |
| Surface dark | `#191C1F` | Elevated dark surfaces |
| Graphite | `#2A2E33` | Secondary dark surface and borders |
| Text muted | `#5F666D` | Supporting text on light |

## Volt discipline

Use Volt for one of four meanings only:

1. The primary action in a decision area.
2. Current/selected state.
3. Positive progress or confirmed completion.
4. A short strategic highlight.

Do not use Volt for long text, large decorative backgrounds, warning states or disabled controls. On light surfaces, pair Volt backgrounds with Carbon text. Never use Volt text on white for body copy.

## Semantic colors

Semantic colors are product-only and never replace the brand palette:

- Success: `#2D7D46`
- Warning: `#A96400`
- Danger: `#B42318`
- Information: `#1769AA`

Always pair color with text or an icon. Status must never be communicated by color alone.

## Distribution guideline

- 70% neutral canvas and space.
- 20% Carbon typography and structure.
- 8% Mist/Concrete support.
- 2% Volt signal.

This is a composition guide, not a mandatory mathematical quota.
