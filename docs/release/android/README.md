# Heldat Google Play release pack

This folder is the source-aligned worksheet for publishing the Android app
`app.heldat.mobile` through Google Play.

- `PLAY_STORE_METADATA.md` contains the English listing copy, access notes, and
  release fields.
- `DATA_SAFETY_MAPPING.md` maps Heldat and its Android SDKs to the Play Data
  safety form.
- `REMAINING_VALUES_CHECKLIST.md` separates completed engineering evidence
  from account-owner, legal, tester, and signed-release inputs.

The exact AAB submitted to Play must be reconciled with these files. Google
Play Console remains the final validator for field limits, policy answers, and
release eligibility.
