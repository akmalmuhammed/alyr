# ALYR's public profiles: texts to paste and the founder's checklist

Growth lane, ALY-230 (part of ALY-227, search and AI visibility, D-056 in PR #123). Written 25 Oct 2026. **Nothing here is published and no account was created.** The founder creates each account, pastes these texts and approves what goes public (`docs/lanes/growth.md`, "Never").

Search engines and AI assistants decide who "ALYR" is by matching the same name, the same line and the same link across the web. So every profile below carries **the same name, the same line and the same description as the site**, word for word. Change a word here only if the site changes it too.

Sources: the site's own words (`apps/web/app/_site/copy.ts`: the homepage's meta description and the line), `docs/company/introduction.md` (D-043, PR #87), `docs/growth/visibility.md` (D-056, PR #123), `docs/brand.md`.

## Rules every profile follows

- **The brand speaks.** No founder name, face or personal story on any profile (D-043). Admin roles stay hidden; see each checklist for where a platform would show a person.
- **No price, offer, trial or "free".** Prices stay off public channels until the commercial registration (D-034).
- **No "AI", "smart", "learns", "automated" or "agent" claims.** The product runs on rules. Product names are left out of the profiles for the same reason ("ALYR Agent" reads as AI; `introduction.md`, open items).
- **Nothing that says ALYR is live or has customers.** No "trusted by", "join", "used by", no numbers about use, no "keep your number", no "live in 48 hours".
- **No WhatsApp or Meta logo**, and nothing implying Meta endorses ALYR. Saying the product works on WhatsApp is a fact; it stays a fact.
- **The Arabic is a draft until the native review (ALY-66).** "ALYR" stays in Latin letters in Arabic text until the founder chooses an Arabic spelling (growth plan, 6.5).

## The founder's checklist

Do the accounts in this order: LinkedIn and Google first (`introduction.md`, "Trust without a face", wants both before the first visits), then Instagram, YouTube, X, Crunchbase, Bing. Tick each line in this file in a small pull request, or tell the Growth lane and it will.

**Before any account**
- [ ] hello@alyr.qa receives mail (ALY-74). Every account below signs up with an ALYR address, never a personal one.
- [ ] Assets from the social studio: the avatar (the ALYR symbol, square, at least 400×400) and banners (LinkedIn 1128×191, X 1500×500, YouTube 2560×1440 with the middle 1546×423 safe). Ask the Growth lane to render them with `alyr-deck-and-social`; the logo files on the design-system branch still carry the old R (`docs/brand.md`), so the avatar is drawn from the site's symbol.
- [ ] Decide once: `alyr_qa` (recommended) or `alyrhq`, for every platform.

**For every account, the same eight steps**
1. [ ] Create it with an ALYR email address; switch on two-step sign-in.
2. [ ] Add a row to `docs/access.md`: the account, who holds it, how it is signed into, 2FA. Never a password.
3. [ ] Name: **ALYR**. Handle or address: the chosen family.
4. [ ] Paste the texts from the platform's section above, English and Arabic.
5. [ ] Category, website (https://alyr.qa) and location as in the table.
6. [ ] Avatar and banner from the studio.
7. [ ] Read the profile on a phone, signed out: same name, same line, same description as alyr.qa; no founder, no price, no "AI", nothing that says ALYR is live.
8. [ ] Post nothing yet. The first posts follow the growth plan and the founder's approval of each.

**Platform notes**
- [ ] **LinkedIn:** the page needs a personal LinkedIn account as its admin. Admins are not shown on the page; but anyone who lists ALYR as their employer appears under the page's "People". To keep the brand speaking alone (D-043), do not add ALYR to a personal profile until that is decided. Add the Arabic version under "Manage languages".
- [ ] **Instagram:** a professional account (Business), linked to ALYR's Meta business portfolio (the one that already holds the WhatsApp app) so the Page, Instagram and WhatsApp sit under one owner.
- [ ] **YouTube:** make the channel as a brand channel on an ALYR Google account, so no personal name or photo is shown. Add the Arabic translation of the name and description.
- [ ] **X:** sign up with the ALYR email; skip the paid tier.
- [ ] **Crunchbase:** claiming or editing a company usually asks for an email on the company's domain (another reason for ALY-74). Leave founded date, legal name and people empty.
- [ ] **Google Business Profile:** only after the company lane's answer in ALY-231. Service-area business, address hidden. Verification may ask for a video or business documents; if it asks for the registration, stop and wait for it.
- [ ] **Bing Places:** import from the verified Google profile.

**Last step, once each profile exists and reads like the site**
- [ ] Add its address to **`NEXT_PUBLIC_ALYR_SAME_AS`** (PR #123, D-056), comma-separated, `https://` only, in the environment the public site is built from: the site's `.env` file on the laptop that runs `scripts/build-site.sh` (see `apps/web/.env.example`), and as a GitHub Actions variable once publishing from GitHub is merged. For example:

  ```
  NEXT_PUBLIC_ALYR_SAME_AS=https://www.linkedin.com/company/alyr-qa,https://www.instagram.com/alyr_qa,https://x.com/alyr_qa,https://www.youtube.com/@alyr_qa,https://www.crunchbase.com/organization/<the address Crunchbase gives>
  ```

  Only profiles that exist and say the same as the site; never one that is planned. The Google and Bing profiles are not listed there: they link to the site from their side. PR #123 must be merged first, or the variable does nothing. Then build and publish with the founder's go-ahead, and check the homepage's structured data shows `sameAs` (Google's Rich Results Test or the page source).
